Tiptap 2 · Vue 2 / Vue 3 · uni-app

为移动端而生的
H5 富文本编辑器

没有常驻工具栏，格式操作收进键盘上方的浮动面板，正文区留出更多空间。 纯 HTML 进出，Vue 2、Vue 3 和 uni-app（H5）都能直接用。

立即体验 Vue 2 示例 查看源码

右侧是真实组件，可直接输入体验

特性

针对小屏和软键盘做了取舍，不追求桌面编辑器的全量能力。

⌨

键盘友好

面板跟随 visualViewport 浮动，iOS / Android 键盘弹起后不被顶飞、不被遮挡。

A

格式齐全

标题 H1–H5、字号、文字颜色、加粗 / 斜体 / 下划线 / 删除线、对齐、行高、缩进。

▤

图文混排

图片、表格、分割线、待办与有序 / 无序列表，粘贴内容按 schema 过滤。

V

Vue 2 / 3 双产物

同一份源码产出两套入口，v-model 分别走 value 与 modelValue，互不干扰。

U

uni-app 可用

H5 端直接使用，取图可接 uni.chooseImage，上传可接 uni.uploadFile。

H

纯 HTML 进出

v-model 就是 HTML 字符串，没有自定义 JSON 协议，前后端存储都简单。

兼容矩阵

默认入口是 Vue 2，Vue 3 必须显式引入 /vue3。

运行时引入方式说明
Vue 2.6+vue-h5-editor 或 /vue2v-model 走 value / input
Vue 3.2+vue-h5-editor/vue3v-model 走 modelValue / update:modelValue
uni-app（H5）按 uni-app 的 Vue 版本选择App / 小程序端不支持，需降级 textarea
原生浏览器dist 下的 UMD 包页面里需先加载对应 Vue 全局构建

接入

安装后两行代码就能跑，样式随 JS 注入，不需要额外引 CSS。

# 安装
npm i vue-h5-editor

# 按需引入
import MobileEditor from "vue-h5-editor";       // Vue 2
import MobileEditor from "vue-h5-editor/vue3";  // Vue 3
<!-- Vue 3 -->
<script setup>
import { ref } from "vue";
import MobileEditor from "vue-h5-editor/vue3";

const html = ref("<p>你好</p>");
</script>

<template>
  <div style="height: 100vh">
    <mobile-editor v-model="html" placeholder="说点什么…" />
  </div>
</template>
